# Wine Quality Assessment Using Physicochemical Properties

## Overview

This project analyses the relationship between physicochemical properties and wine quality using Python, statistical analysis, exploratory data analysis (EDA), and multiple linear regression.

The objective is to identify the laboratory measurements most strongly associated with wine quality and evaluate whether these measurements can be used to predict wine quality scores.

## Problem Statement

Traditional wine quality assessment relies on sensory evaluation, which may be subjective and time-consuming. This project investigates whether physicochemical measurements can support a data-driven wine quality assessment process.

## Objectives

- Calculate descriptive statistics for alcohol, volatile acidity, and residual sugar.
- Compare relative variability using the coefficient of variation.
- Analyse the relationship between alcohol content and wine quality using Pearson correlation.
- Visualise quality score distributions using a histogram and box plot.
- Explore relationships between attributes using a correlation heatmap.
- Develop a multiple linear regression model using 11 physicochemical attributes.
- Evaluate the model using MAE, MSE, RMSE, and R-squared.
- Identify influential predictors using standardized regression coefficients.
- Examine multicollinearity using Variance Inflation Factor (VIF).
- Provide recommendations for laboratory-based quality screening.

## Dataset

The project uses the **Red Wine Quality Dataset**, containing 1,599 observations.

- **Input features:** 11 physicochemical attributes
- **Target variable:** `quality`
- **Data format:** CSV

### Features

1. Fixed acidity
2. Volatile acidity
3. Citric acid
4. Residual sugar
5. Chlorides
6. Free sulfur dioxide
7. Total sulfur dioxide
8. Density
9. pH
10. Sulphates
11. Alcohol

Dataset source: [UCI Machine Learning Repository — Wine Quality](https://archive.ics.uci.edu/dataset/186/wine+quality)

## Methodology

### 1. Statistical Analysis
Calculated the mean, median, mode, standard deviation, and skewness for selected attributes. The coefficient of variation was used to compare relative variability, and Pearson correlation was used to examine the relationship between alcohol and quality.

### 2. Exploratory Data Analysis
Created the following visualisations:

- Histogram of wine quality scores
- Box plot of alcohol content grouped by quality score
- Correlation heatmap of physicochemical attributes and quality

### 3. Predictive Modelling
Developed a multiple linear regression model using all 11 physicochemical attributes.

- Training data: 80%
- Testing data: 20%
- Random state: 42

### 4. Model Evaluation
Evaluated predictive performance using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

Standardized regression coefficients and VIF were also examined.

## Key Findings

- Residual sugar showed the greatest relative variability among the three selected attributes.
- Alcohol had the strongest positive Pearson correlation with quality.
- Volatile acidity had the strongest negative Pearson correlation with quality.
- Alcohol and volatile acidity were the two leading predictors based on standardized regression coefficient magnitudes.
- The regression model explained approximately 40.32% of the variation in test-set quality scores.

## Business Recommendations

Alcohol content and volatile acidity deserve particular attention during laboratory-based wine quality screening.

The regression model can help identify samples for further investigation. However, its predictive performance is not sufficient to justify completely replacing sensory evaluation.

## Limitations

- The dataset contains duplicate observations that may affect train-test evaluation.
- Quality scores are concentrated around the middle categories.
- The model uses only the available physicochemical attributes.
- Linear regression may not capture all nonlinear relationships influencing wine quality.
